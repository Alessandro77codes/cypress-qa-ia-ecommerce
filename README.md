# 🛒 Automação de Testes E-Commerce — Cypress & Page Object Model (POM)

Repositório voltado para a demonstração de testes automatizados de ponta a ponta (E2E) utilizando o framework **Cypress** e arquitetura baseada no padrão **Page Object Model**, aplicado em um cenário real de e-commerce.

---

## 🚀 Tecnologias e Ferramentas Utilizadas
* **Cypress**: Framework de automação de testes front-end rápido e moderno.
* **JavaScript**: Linguagem base para escrita dos scripts de teste.
* **Page Object Model (POM)**: Padrão de projeto utilizado para aumentar a manutenibilidade e o reaproveitamento de código, isolando a estrutura das páginas da lógica de teste.
* **Git & GitHub**: Controle de versão e hospedagem do código.

---

## 🛠️ Funcionalidades Automatizadas até o Momento
* **Navegação Inicial**: Validação de renderização e fluxo de acesso à área de autenticação.
* **Cenários de Login (Aula 2)**:
  * ❌ *Fluxo de Exceção*: Tentativa de login com credenciais incorretas e validação da mensagem de erro do sistema.
  *  *Fluxo Feliz*: Login bem-sucedido utilizando credenciais válidas e verificação de sessão ativa.
